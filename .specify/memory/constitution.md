# POS_API Constitution

## Core Principles

### I. Precision and Explicit Structure
Code MUST be precise. There is absolutely no room for assumption in the implementation. The structure of the codebase MUST be explicit, precise, and strictly adhered to across all layers (Controllers, DTOs, Entities, Repository, Implementation).

### II. Graphify-Driven Workflow
Using all graphify skills is a MUST before and after for each and every change. Graphify serves as the definitive knowledge base of our codebase and MUST be consulted prior to making changes, and updated immediately after changes to maintain an accurate architectural map.

### III. Responsive UI Design
All UI design and implementation MUST be completely responsive, providing a seamless and optimized experience across both mobile and desktop interfaces.

## Governance

This constitution supersedes all other practices. All code changes and reviews MUST verify compliance with these principles.
